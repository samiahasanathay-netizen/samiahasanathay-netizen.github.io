Photography

Frames from set, from the street, and everywhere in between.

A running collection of photography — behind-the-scenes stills from shoots, event coverage and personal work. This page is set up and ready; add your own images to bring it to life.

Setting this page up: drop your image files into assets/photography/, then in photography.html replace a <span class="ph">…</span> placeholder with <img src="assets/photography/your-file.jpg" alt="…">. Each <figure> is one gallery tile — add or remove <figure> blocks to change the count, and edit the <figcaption> text for the caption shown on hover.
